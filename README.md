# 👁️ Vision Core Projects

This repository contains my experimental and production-ready Computer Vision scripts. The focus is on bridging complex spatial mathematics with real-time interactivity.

## 🛠️ Tech Stack
*   **Python 3**
*   **OpenCV (cv2) & MediaPipe:** For core spatial tracking and hand/pose estimation.
*   **YOLOv8 / YOLO11:** For high-speed, real-time object detection.
*   **Pygame:** For rendering interactive visual feedback loops.

## 📁 Core Modules
*   `kinesis_core.py` & `spartan_core.py`: Core logic for movement and gesture tracking.
*   `aero_canvas.py`: Interactive virtual drawing/interaction environments.
*   `holo_strike.py` & `aegis_reflect.py`: Gesture-based interactive visual systems.
*   `yolo_day1.py`: Baseline object detection testing using local YOLO weights.

*Note: Model weights (.pt files) and test media (.mp4) are processed locally on an RTX 4060 Ti and are excluded from this repository to save space.*
